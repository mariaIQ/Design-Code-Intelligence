# React Frontend

Inspect the existing repository, framework, conventions and component library before changing code. Preserve the chosen stack unless the user asks to replace it.

Translate designs into reusable components and semantic tokens. Maintain traceability between Figma variants and React props, states and responsive behaviour. Use semantic HTML, keyboard-complete interaction, visible focus, appropriate ARIA, reduced-motion support and accessible validation.

Model loading, empty, error, partial, permission and recovery states—not only the happy path. Keep business rules separate from presentation. Prefer composable components and clear data boundaries over one large screen component.

Verify with the repository's typecheck, lint and tests. Where possible, exercise responsive layouts and critical interactions. Report any visual or behavioural assumptions that could not be verified from the source design.
